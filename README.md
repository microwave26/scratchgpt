## 👋 Welcome to ScratchGPT!

**ScratchGPT** is an AI chatbot project built with Scratch-style blocks and a custom AI extension. Chat with an AI, explore its conversation memory, and see what you can create!

## 🚀 Getting Started

1. **Download** the latest project file: [ScratchGPT.sb3](https://github.com/microwave26/scratchgpt/releases/latest/download/ScratchGPT.sb3).
2. Open [TurboWarp](https://turbowarp.org).
3. Load the downloaded `.sb3` project into TurboWarp.
4. Follow the custom extension setup instructions if prompted.

## ✨ Features

- 💬 AI-powered conversations
- 🧠 Conversation history and memory
- 👥 Separate chat sessions by username
- 🔄 Resettable conversation memory
- ⚡ Powered by the Groq API

## ℹ️ Important Information

ScratchGPT uses a custom AI extension that is designed for **TurboWarp**. The standard Scratch editor does not support arbitrary custom extensions, so ScratchGPT will not work there as-is.

The extension communicates with an online server to generate AI responses, so an internet connection is required. Availability and response speed depend on the server and the AI provider's usage limits.

**Note:** Bugs and unexpected behavior may occur.
